编码说明：自动模式按配置优先级筛选本机发送与接收均支持的 LiveKit 编码。H.265 不保证硬件加速；仅 AV1 / VP9 使用 SVC，其他编码使用可用的 simulcast 回退。2.23.0 对屏幕 SVC 可能降为 L1T3 并将内容提示改为 motion。H.264 备用编码也须本机支持；远端支持情况由 SFU 协商决定。本页不修改 SDP 或关闭拥塞控制。
